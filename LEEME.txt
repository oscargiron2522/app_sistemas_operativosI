LINUXCORE - PROYECTO PHP VISUAL COMPLETO

REQUISITOS
- Windows con XAMPP (Apache y PHP).
- Navegador actualizado.
- Internet para cargar Font Awesome y Chart.js desde CDN.

INSTALACIÓN
1. Extrae el ZIP.
2. Copia la carpeta LinuxCore_Completo dentro de C:\xampp\htdocs\
3. Inicia Apache en XAMPP.
4. Abre http://localhost/LinuxCore_Completo/
5. Para ver el inicio de sesión: http://localhost/LinuxCore_Completo/login.php

PÁGINAS INCLUIDAS
- Dashboard
- Procesos
- CPU y Memoria
- Planificación de CPU
- Interbloqueos
- Almacenamiento
- Usuarios y Grupos
- Terminal Web
- Reportes
- Inicio de sesión visual

ESTRUCTURA
index.php                  Router principal
login.php                  Pantalla de inicio de sesión demostrativa
includes/header.php        Encabezado y navegación compartidos
includes/footer.php        Pie de página compartido
includes/functions.php     Funciones comunes
pages/                     Vistas de cada módulo
assets/css/styles.css      Estilos del sistema
assets/js/app.js           Interacciones y gráficas

IMPORTANTE
Esta entrega es un prototipo visual con datos ficticios/de demostración. Los botones de acciones destructivas no ejecutan cambios reales, y la terminal solo simula una lista limitada de comandos. El login no es autenticación segura. No expongas este prototipo a una red pública.

Para conectarlo a Ubuntu después, habrá que implementar una API/backend con permisos controlados para leer métricas reales y ejecutar operaciones autorizadas. No es seguro ejecutar texto arbitrario recibido desde un formulario PHP como comando de shell.
